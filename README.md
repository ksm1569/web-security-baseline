# web-security-baseline

웹 개발자를 위한 최소한의 보안 체크리스트.\
항목마다 확인 방법을 붙였다.

> 이 체크리스트를 통과하지 못하면 보안 최소요건을 갖추지 못한 것이다.\
> 통과했다고 안전이 보장되지는 않는다.

OWASP Top 10이나 ASVS의 요약·번역본이 아니다.\
실무에서 되풀이되는 실수를 중심으로 항목을 골랐다.\
끝까지 점검할 수 있도록 항목은 40개를 넘기지 않는다.

침투 테스트 절차, WAF·SIEM 같은 보안 솔루션 도입·운영, 네이티브 모바일·데스크톱 앱, ISMS-P·개인정보보호법 같은 컴플라이언스 전체 대응은 범위 밖이다.

## 점검 시점

- 프로젝트 착수 직후.\
  템플릿이나 보일러플레이트를 복사했다면 딸려 온 설정과 코드까지 본다.
- 운영 오픈 전
- 인증·권한·파일 처리 기능을 추가하거나 바꾼 뒤

## 사용법

1. [`templates/audit-record.md`](templates/audit-record.md)를 프로젝트로 복사한다.
2. 프로젝트에 해당하는 [적용 태그](#적용-태그)를 모두 고른다.\
   고르지 않은 태그의 항목은 해당없음이 된다.
3. [체크리스트](#체크리스트)의 항목마다 확인 방법대로 점검하고 통과·미통과·해당없음 중 하나를 적는다.\
   점검 기록의 근거 칸에는 실제로 확인한 내용(보낸 요청과 받은 응답, 검색 결과, 설정 파일 위치)을, 해당없음이면 그 이유를 적는다.

모든 항목이 통과나 해당없음이고 근거가 남아 있으면 "v1.0.0 기준 최소요건 충족"이라고 할 수 있다.\
기준은 버전마다 다르므로 점검 기록에 이 저장소의 버전을 함께 적는다.

## 체크리스트

코드와 설정이 어디서 실행되고 적용되는지를 기준으로 나눴다.

| 분류 | 범위 |
| --- | --- |
| [프론트엔드](checklist/frontend.md) | 브라우저에서 실행되는 코드와 빌드 산출물 |
| [백엔드](checklist/backend.md) | 서버에서 실행되는 코드. 서버 템플릿 렌더링 포함 |
| [DB](checklist/database.md) | DB 계정·권한과 데이터 저장 방식 |
| [인프라](checklist/infra.md) | OS·WAS·웹서버·클라우드 리소스 설정 |
| [네트워크](checklist/network.md) | 전송 구간 암호화와 접근 경계 |
| [공통](checklist/common.md) | 설정 위치가 프로젝트마다 다르거나 개발·배포 과정 전반에 걸친 것 |

여러 레이어에 걸친 주제는 레이어별 항목으로 나눴다.\
파일 업로드라면 백엔드에서 확장자·크기·파일명 검사를, 인프라에서 저장 위치의 스크립트 실행 차단을 따로 점검한다.\
한 항목에 몰아 두면 개발자와 서버 담당자가 서로 상대가 확인했으리라 여기고 넘어가기 쉽다.

## 항목 형식

항목 제목은 "서버가 요청 대상 리소스의 소유자를 확인하는가"처럼 예·아니오로 답할 수 있는 질문이다.\
본문에는 아래 내용을 적는다.

- **적용**: 해당하는 [적용 태그](#적용-태그)
- **위험**: 공격자가 실제로 할 수 있는 일과 그 결과
- **기준**: 통과 조건
- **하지 말 것**: 조치한 것처럼 보이지만 실제로는 막지 못하는 흔한 해법
- **확인 방법**: 직접 해 볼 행동(요청 보내기, 코드 검색, 설정 확인)과 확인할 결과
- **근거**: ASVS 요구사항 ID와 행안부 가이드의 보안약점 명칭

항목 본문은 특정 언어나 프레임워크에 묶이지 않게 쓴다.\
스택별 확인 방법(검색 패턴, 설정 위치, 코드 예)은 [`stack/`](stack/)에 따로 둔다.

## 적용 태그

| 태그 | 대상 |
| --- | --- |
| 공통 | 모든 웹 서비스 |
| `SSR` | 서버가 HTML을 렌더링한다 |
| `SPA` | 브라우저 JS가 화면을 그리고 API를 호출한다 |
| `쿠키인증` | 세션 쿠키로 인증한다 |
| `토큰인증` | Authorization 헤더 등에 토큰을 실어 인증한다 |
| `클라우드` | 퍼블릭 클라우드 리소스를 쓴다 |

파일 업로드, OS 명령 실행처럼 그 기능이 있을 때만 해당하는 항목도 적용은 공통이다.\
그 기능이 없으면 해당없음으로 적는다.
