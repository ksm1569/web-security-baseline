# BE-OUT-01 서버가 HTML을 만들 때 값을 출력 위치에 맞게 이스케이프하는가

- **적용**: `SSR`
- **위험**: 공격자가 검색 링크나 게시글 제목에 심은 스크립트가 그 화면을 연 사용자의 브라우저에서 실행되어, 그 사용자 권한으로 글을 쓰거나 설정을 바꾸고 화면의 개인정보를 가져간다.
- **기준**: 개발자가 정한 고정 문자열이 아닌 값은 출력할 때 위치에 맞게 이스케이프한다.\
  에디터로 받은 HTML처럼 태그를 살려서 보여 줘야 하는 값은 BE-OUT-02에서 본다.
  - HTML 본문·속성: HTML 이스케이프
  - `<script>` 안: JS 이스케이프
  - `onclick` 같은 이벤트 속성 안: JS 이스케이프 뒤 HTML 이스케이프
  - 사용자가 준 URL을 `href`·`src`에 통째로 넣을 때: 출력할 때 `http:`·`https:`인지 확인
- **하지 말 것**:
  - JSP처럼 기본 출력이 이스케이프되지 않는 엔진에서 `${}`·`<%= %>`로 값을 바로 출력하기.
  - 관리자만 입력하는 값이라며 Thymeleaf의 `th:utext`, Jinja2의 `|safe`, Blade의 `{!! !!}` 같은 이스케이프하지 않는 문법을 쓰기.\
    관리자 계정을 빼앗기면 그 값이 모든 사용자 화면에서 실행된다.
  - 출력 이스케이프 대신 요청을 받거나 저장할 때 `<`·`>`를 지우거나 바꾸는 XSS 필터에 맡기기.\
    속성 안에서는 `" autofocus onfocus="alert(1)`처럼 `<`·`>` 없이도 스크립트가 실행된다.\
    일괄 등록, 외부 연동, 필터를 넣기 전에 쌓인 데이터처럼 필터를 거치지 않은 값은 그대로 나간다.\
    필터가 바꿔 둔 값은 출력할 때 한 번 더 이스케이프되어 화면에 `&lt;`가 글자로 보이고, 이걸 고치려고 출력 문법을 이스케이프하지 않는 쪽으로 바꾸는 일이 흔하다.
  - HTML 이스케이프 하나로 모든 위치를 처리하기.\
    브라우저는 속성 값의 엔티티를 먼저 풀고 나서 링크나 JS로 쓴다.\
    그래서 `href`의 `javascript:alert(1)`, `onclick="view('값')"` 안의 `');alert(1);//`는 HTML 이스케이프를 해도 실행된다.
- **확인 방법**: 아래 단계에서 미통과가 하나라도 나오면 이 항목은 미통과다.
  1. 입력값이 다시 화면에 나오는 곳을 고른다.\
     검색 결과, 게시글 제목, 회원 이름, 오류 메시지 같은 곳이다.\
     저장된 값은 관리자 목록이나 알림처럼 다른 화면에도 나오므로 그 화면도 함께 본다.
  2. 각 입력에 `"'><b>xss01</b>`를 넣고 응답 원문에서 `xss01`을 찾는다.\
     응답 원문은 curl이나 개발자 도구 Network 탭의 응답 본문으로 본다.\
     Elements 탭은 브라우저가 해석한 뒤의 모습이라 판단에 쓰지 않는다.\
     넣은 자리에서 `<`·`"`·`'` 중 하나라도 `&lt;`·`&quot;`·`&#39;` 같은 엔티티로 바뀌지 않았으면 미통과다.\
     속성 값이 따옴표로 감싸여 있지 않아도 미통과다.
  3. 값이 `<script>` 안이나 이벤트 속성 안에 나오는 곳에는 `xss01'"</script>`를 넣는다.\
     넣은 자리에 `</script>`가 그대로 있으면 미통과다.\
     값을 감싼 따옴표가 앞에 `\` 없이 나와도 미통과다. 이벤트 속성 안이면 `&#39;`처럼 엔티티로 바뀌었어도 `\`가 없으면 미통과다.\
     값이 따옴표 밖에 그대로 들어가도 미통과다.
  4. 사용자가 넣은 URL이 `href`·`src`로 나가는 곳에는 `JavaScript:alert(1)`을 넣는다.\
     응답의 `href`·`src`가 대소문자와 상관없이 `javascript`로 시작하면 미통과다.
  5. 템플릿 파일과, 코드에서 문자열을 이어 붙여 HTML을 만드는 곳에서 이스케이프하지 않는 출력을 찾는다.\
     찾은 곳마다 값이 어디서 오는지 따라가서 개발자가 정한 고정 문자열이 아니면 미통과다.\
     템플릿 엔진 설정에서 자동 이스케이프를 꺼 두었다면 기본 출력 문법도 이스케이프하지 않는 출력으로 보고 같은 방법으로 따라간다.
